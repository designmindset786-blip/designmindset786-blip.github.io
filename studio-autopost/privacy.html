Privacy Policy

Studio Autopost ("the app") is a private tool operated by a single owner to publish the owner's own videos to the owner's own social media accounts. This policy explains what data the app uses.

Data the app accesses

  • YouTube (Google): with the owner's permission, the app uses the YouTube Data API to upload videos, set their title, description, privacy and publish time, and read the status of those uploads on the owner's channels.
  • Instagram and Facebook (Meta): with the owner's permission, the app publishes Reels, captions and a first comment to the owner's Instagram professional accounts and Facebook Pages, and reads the publishing status.

How the data is used and stored

Access tokens are used only to publish the owner's own content. They are stored encrypted in the owner's private GitHub repository secrets and on the owner's own computer. The app does not collect, sell, share or analyse personal data of any other person, and it does not use the data for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; by using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

Data deletion

To remove the app's access, revoke it in your Google account permissions or in Instagram/Facebook settings (Apps and websites). The owner deletes the stored tokens when access is revoked or on request through the contact link below.
